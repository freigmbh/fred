# Admin UI

Static Vite app for the single admin. Read the root `AGENTS.md` first.

- One admin, one secret. `ADMIN_SECRET` is stored in `localStorage` after login and sent as `adminSecret` on every admin call. There are no roles and no sessions.
- Every admin call goes through `src/lib/admin.ts`: `useAdminQuery` adds the stored secret to a query, `useAdminCall` runs one mutation or action at a time, and `errorText` is the one line any failure shows. A rejected secret logs out through `signOutIfRejected`, wherever the call ran, and the login form says so. `UnauthorizedBoundary` is keyed by secret and page, so an error never outlives either.
- The Projects page is the writable UI: connect or replace a project's token through `admin.connectProject`, `admin.checkProject`, two-step `admin.disconnectProject`, save the review pipeline through `admin.savePipeline`, and refresh the catalog through `admin.refreshModels`. Preserve edits on failure and reject stale pipeline saves. The pasted token goes only to `connectProject`; the UI never receives a stored token. Other writes stay in the Convex dashboard or GitLab.
- Nav is Overview, Queue, Reviews, Spend, Projects, Export. Projects is master-detail: connected projects first, then projects FRED has seen but that are not connected, each with a health dot. Warn within 30 days of token expiry; show failure once expired or when the last check recorded a problem.
- Data comes only from `admin.*` functions in `apps/controller/convex/admin.ts`. Types flow from the controller's generated API through `src/lib/api.ts`; never hand-write result types. Prefer having the controller return a number or flag over recomputing it here.
- Domain words live once: severities, statuses, failure kinds, their tones, and short forms such as SHAs and MR labels in `src/lib/display.ts`; token health, pipeline checks, and project grouping in `src/lib/projects.ts`. Lists and label maps are typed against the API's unions, so a new value fails the typecheck until it gets a word. A time window that feeds a query comes from `useWindowStart`, so its arguments stay stable.
- Pure helpers in `src/lib/` get focused vitest tests (`*.test.ts`, the `ui` project); components have none.
- shadcn with the Base UI style and Tailwind v4. Components live in `src/components/ui/` and are added with `pnpm dlx shadcn@latest add <name>` from this directory. Pages live in `src/routes/`, small shared marks in `src/components/marks.tsx`.
- Brand: the Settings language in light and dark. Neutral surfaces, grouped inset boxes with hairline rows, Frei green as accent and the selected nav pill, an ink primary button that becomes paper in dark, Bordeaux and amber for failures and warnings (lifted in dark). Dark is neutral gray, never green-tinted. Providers keep their own colors, FRED green, Claude orange, and Codex ink that becomes paper in dark, always next to the word. Overview shows a retired bot only in a month in which it completed reviews; the Reviews filter offers every bot. Tokens are in `src/index.css`, one block per mode; the preference lives in `localStorage` under `fred.theme` through `src/lib/theme.ts`. shadcn tokens keep their stock meaning: `--primary` is the ink button, `--accent` a neutral hover surface, `--sidebar-primary` the green nav pill. Frei green for links and marks is `--brand` (`text-brand`, `bg-brand`), focus stays green through `--ring`, and the nav icon tiles are `--nav-*`. The root is 16px; body text is `text-sm` (13px) and stock primitives use `text-xs`.
- Stock primitives stay stock: add or update them with the CLI and change the look through tokens, not classes inside `components/ui/`. The one project addition is `NativeSelect`'s `face` prop and `SelectPrefix`. Icons are `lucide-react`. Shared layout is in `src/components/group.tsx` (`Box` is a flush `Card`, `Row` an `Item`).
- Terse. Labels over sentences; no idle hints or status lines that restate the obvious. Show a message only for an outcome or a problem, in one short line. Secondary facts go into a `title` tooltip or the docs.
- Static when idle. Charts do not animate on mount; motion is hover and click only.
- Every table and chart has an empty state.
- Production is the static bundle nginx serves on the same origin as the `/api` proxy, the `web` service on the Docker stack. Development sets `VITE_CONVEX_URL` to the local Docker instance printed by `pnpm fred dev up`.
